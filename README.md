# enduragrip-website
One-page website for EnduraGrip Adhesives (HTR-927), served by GitHub Pages at https://enduragrip-adhesives.com.

- `index.html`: the page
- `assets/`: logo (SVG and PNG)
- `docs/`: downloadable PDFs (`HTR-927-Instructions.pdf`, `HTR-927-SDS.pdf`)
- `CNAME`: custom domain for GitHub Pages
